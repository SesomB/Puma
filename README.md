# Puma

**Build instructions:**
1) Clone the repo: 
```console
 $ git clone https://github.com/SesomB/Puma.git --recursive
```

2) Create a `build` directory and change into it: 
```console
 $ mkdir build && cd build
```
3) Run CMake: 
```console
 $ cmake ..
```
4) Run Make: 
```console
 $ make
 ```
5) Run Puma! 
```console 
 $ sudo ./build/bin/Puma -v trace
```
